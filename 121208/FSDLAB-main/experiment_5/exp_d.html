The CSS Box Model

Every HTML element is essentially a rectangular box. The box model consists of margins, borders, padding, and the actual content.

Box Model Layers Explained

Margin: Clears an area outside the border. The margin is transparent. (Shown above as dashed outline)
Border: A border that goes around the padding and content. (Solid dark blue: 15px)
Padding: Clears an area around the content. The padding is transparent, but shows the element's background color. (Space between text and border: 30px)
Content: The content of the box, where text and images appear. (Light blue background: 200px width, 100px height)
